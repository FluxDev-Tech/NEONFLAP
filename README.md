# ⚡ NEON FLAP

**Survive the drift. Fly through the neon forest.**

Neon Flap is a futuristic, high-octane reimagining of the classic "Flappy" genre. Built with a sleek vaporwave aesthetic, responsive physics, and progressive difficulty, it's designed to be played anywhere—from your desktop browser to your mobile home screen.

---

## 🚀 Key Features

- **Neon Aesthetic:** High-contrast visuals with glowing silhouettes and pulse animations.
- **Dynamic Difficulty:** The game speed gradually increases as you score higher, keeping the challenge fresh.
- **Hall of Fame:** Local high-score tracking saves your top 5 best runs.
- **Smooth Physics:** Powered by `Matter.js` for satisfying, weight-based flight.
- **PWA Ready:** Install the game directly to your phone or desktop for offline play and a full-screen experience.
- **Fully Responsive:** Optimized for touch, mouse, and keyboard inputs.

---

## 📱 Mobile Installation (APK-like Experience)

You don't need to go to an app store to install Neon Flap. It uses **PWA (Progressive Web App)** technology to provide a native-app feel.

### For Android (Chrome)
1. Open the game link in **Google Chrome**.
2. Tap the **"Three Dots"** menu in the top right corner.
3. Select **"Install App"** or **"Add to Home Screen"**.
4. A "Neon Flap" icon will appear on your home screen.

### For iPhone/iOS (Safari)
1. Open the game link in **Safari**.
2. Tap the **"Share"** button (square with an up arrow) at the bottom.
3. Scroll down and tap **"Add to Home Screen"**.
4. Tap **"Add"** in the top right corner.

---

## 🕹️ How to Play

### **Controls**
- **Desktop:** Press **SPACE** or **Click** the screen to flap. Press **P** or **ESC** to pause.
- **Mobile/Tablet:** **Tap anywhere** on the screen to flap. Use the pause button in the top right.

### **Goal**
Navigate the neon bird through the gaps in the energy pipes. Each pipe passed increases your score. If you hit a pipe or the boundaries, the flux engine fails and the game ends!

## 🛠️ Technology Stack

- **Framework:** React 18
- **Build Tool:** Vite
- **Physics Engine:** Matter.js
- **Animations:** Motion (formerly Framer Motion)
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Persistence:** LocalStorage (for scores)

## 🛠️ Local Development

If you want to run this project locally:

1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```
